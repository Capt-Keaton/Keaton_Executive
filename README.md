# Keaton Clarke Portfolio

Four-page aviation-themed portfolio (Home, Experience, Skills & Wins, Contact).

Files:
- index.html  (the website, no build step)
- Keaton_Clarke_Resume.pdf  (the download button on the Contact page)

## Publish on GitHub Pages
1. Sign in at github.com and click New repository. Name it `keaton-portfolio` (or `YOURUSERNAME.github.io` for a shorter link). Set it to Public.
2. Click "uploading an existing file" and drag in `index.html` and `Keaton_Clarke_Resume.pdf`. Keep both in the same folder. Click Commit changes.
3. Go to Settings > Pages. Under Build and deployment, choose Source: Deploy from a branch, Branch: main, folder: / (root). Click Save.
4. Wait 1-2 minutes. Your link will be:
   https://YOURUSERNAME.github.io/keaton-portfolio/
   (or https://YOURUSERNAME.github.io/ if you used the short repository name)
